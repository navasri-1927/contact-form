# contact form

This repository contains a simple and responsive form built using **HTML** and **CSS**. It's a great starting point for beginners looking to understand form structure, styling design principles.

## 🚀 Features

- Clean and modern UI
- Custom input styles
- Button hover effect

## 🛠️ Built With

- HTML5
- CSS3 (Flexbox/Bootstrap)
